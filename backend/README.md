# EarnSecure Backend

FastAPI-based backend for the EarnSecure parametric insurance platform. This service provides REST APIs for rider onboarding, dynamic premium calculation, policy management, claims processing, and administrative oversight.

## Quick Start

### 1. Environment Setup
**Using venv (Recommended):**
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

**Using Conda:**
```bash
conda create -n earnsecure python=3.11 -y
conda activate earnsecure
pip install -r requirements.txt
```

### 2. Deployment Commands

| Environment | Command |
| :--- | :--- |
| **Development** | `uvicorn app.main:app --reload --port 8000` |
| **Production (Gunicorn)** | `gunicorn -k uvicorn.workers.UvicornWorker -w 4 -b 0.0.0.0:8000 app.main:app` |
| **Production (Uvicorn)** | `uvicorn app.main:app --host 0.0.0.0 --port 8000 --workers 4 --proxy-headers` |

> **Pro-Tip:** For production, calculate workers using $(2 \times \text{cores}) + 1$. Always run behind a reverse proxy like Nginx for SSL termination and buffering.

## Architecture

The project follows a modular FastAPI structure to ensure scalability and ease of testing.

* **`app/routers/`**: Modular endpoints mirroring frontend API clients.
* **`app/schemas/`**: Pydantic models for strict request/response data validation.
* **`app/models/`**: (Planned) SQLAlchemy or Tortoise ORM models for database persistence.
* **`app/services/`**: Logic for premium calculation (GBR + cohort blending) and third-party integrations.
* **`app/storage.py`**: Current in-memory demo store (to be replaced by PostgreSQL/Redis).

## Admin access

### Overview
The backend exposes admin endpoints under `/admin/*`. To authenticate as an admin:
- Preferred: set `ADMIN_PASSWORD_HASH` to a bcrypt hash (generated by Passlib/bcrypt).
- Simple fallback: set `ADMIN_SECRET_HASH` to a SHA256 hex of your admin password.

### Set the admin password hash
On macOS:
```bash
echo -n 'my-secret-password' | shasum -a 256 | awk '{print $1}'
```
On Linux:
```bash
echo -n 'my-secret-password' | sha256sum | awk '{print $1}'
```
Or using Python:
```bash
python3 - <<'PY'
import hashlib
print(hashlib.sha256(b'my-secret-password').hexdigest())
PY
```

Create `backend/.env.local` (the app loads this automatically) with:
```env
ADMIN_SECRET_HASH=<paste-hex-here>
JWT_SECRET=your-jwt-secret-override
# Optional: DATABASE_URL=postgres://...
```

### Quick curl examples
Login and obtain a token:
```bash
API=http://127.0.0.1:8000
curl -s -X POST "$API/admin/login" -H 'Content-Type: application/json' -d '{"password":"my-secret-password"}' | jq .
```
Use the token to call an admin endpoint:
```bash
TOKEN=$(curl -s -X POST "$API/admin/login" -H 'Content-Type: application/json' -d '{"password":"my-secret-password"}' | jq -r .access_token)
curl -H "Authorization: Bearer $TOKEN" "$API/admin/portfolio"
```

### Notes
- The server checks `ADMIN_PASSWORD_HASH` first, then falls back to SHA256 using `ADMIN_SECRET_HASH`.
- Change `JWT_SECRET` in production; default is `earnsecure-dev-secret-change-me-32b`.
- For local dev you can also export `ADMIN_SECRET_HASH` in your shell instead of using `.env.local`.
