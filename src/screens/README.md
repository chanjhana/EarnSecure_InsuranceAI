# EarnSecure React Native UI (Expo)

## How to run

1. Install dependencies:
   - `npm install`
2. Start Expo:
   - `npx expo start`
3. Open the app in Expo Go or a simulator.

## Migration checklist

- Add logo and platform icon assets under `assets/` and replace TODO comments in screens.
- Confirm required fonts and set a custom font family (optional).
- Wire real OTP, platform ID validation, and premium pricing API.
- Replace placeholder trigger data with live feeds.
- Add analytics and error tracking hooks.
